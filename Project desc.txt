ALS Truck Maintenance

Developed a VR-based ALS Truck Maintenance Training Simulator for Edgeforce Solutions Pvt. Ltd., designed to provide Army personnel with an immersive and hands-on platform for learning vehicle maintenance procedures. The simulator reduces dependency on physical training vehicles, minimizes maintenance costs, and enables trainees to safely practice complex maintenance tasks in a virtual environment.

The application features Basic, Intermediate, and Advanced training modules. The Basic module introduces vehicle components and maintenance procedures, while the Intermediate and Advanced modules allow trainees to perform guided and independent assembly and disassembly of truck components. A Time Trial mode evaluates trainees based on speed, accuracy, and adherence to maintenance procedures, providing real-time performance feedback and scoring.

Key Contributions & Technologies

> Developed the simulator using Unity, C#, and the latest Meta XR SDK for immersive VR interactions.
> Collaborated with Army personnel to gather technical data, maintenance procedures, and training requirements to ensure technical accuracy.
> Implemented advanced socket-based interaction systems for precise assembly and disassembly of truck components, enabling realistic part alignment, snapping, validation, and procedural workflows.
> Created engine and vehicle system animations to demonstrate the internal working of mechanical systems and maintenance concepts.
> Utilized Spline tools for guided interactions, object movement, and training workflows.
> Built gameplay systems, UI, training logic, time-based challenges, scoring, and performance evaluation using C#.
> Developed an Admin Dashboard for monitoring trainee activities, managing student records, and generating detailed training and performance reports.

Command Center

Command Center is a custom VR and Web-based Remote Assistance Platform developed for Hindustan Aeronautics Limited (HAL). The platform enables field technicians using Meta Quest 3/3S to securely collaborate with remote experts through live video, two-way audio, and real-time communication. It allows professionals to remotely inspect, diagnose, and guide on-site personnel during maintenance and operational procedures, reducing travel time and improving response efficiency.

Technical Highlights

> Developed the VR client using Unity, C#, and the latest Meta XR SDK.
> Integrated the Meta Quest 3/3S Passthrough Camera API to capture and stream live first-person video.
> Built APIs to securely transmit the headset's live video feed to a web-based server.
> Developed a dedicated Audio Engine supporting low-latency two-way voice communication, along with live chat, device-specific mute, and remote disconnect controls.
> Designed the platform to support 5+ concurrent users with synchronized communication sessions.
> Optimized the streaming pipeline to deliver 720p real-time video on internet connections as low as 2 Mbps.
> Developed the backend using Node.js for authentication, session management, media handling, and communication services.
> Utilized SQLite to store user information, screenshots, session recordings, activity logs, and communication history.
> Implemented a comprehensive Network Monitoring & Analytics system to track bandwidth, latency, connection quality, packet statistics, and streaming health in real time.
> Designed and developed intuitive web dashboards for monitoring active sessions, connected devices, recordings, user activity, and overall system performance.

This project combines XR, real-time media streaming, networking, backend development, and system architecture to deliver a robust industrial remote assistance solution for mission-critical field operations.

Navika AI - IDeX Navy

Navika AI is a Mixed Reality (MR) AI Assistant designed to simplify troubleshooting and maintenance of ship systems through immersive guidance. I served as the Core Developer and Software/System Architect, designing the overall application architecture and developing the end-to-end workflow that seamlessly integrates Mixed Reality, AI inference, and real-time communication into a unified troubleshooting platform.

The application enables technicians to capture live views of ship components, electrical circuits, and mechanical systems using an MR headset. The captured feed is transmitted to a locally hosted AI server, trained on ship maintenance manuals, technical documentation, and troubleshooting procedures. The AI analyzes the scene and returns contextual guidance in under 10 seconds, which is displayed directly within the user's field of view as 3D overlays, reference images, keywords, and step-by-step repair instructions. The platform also supports two-way voice communication and live chat, enabling seamless collaboration between technicians and remote experts.

Technical Highlights
> Served as the Core Developer and Software/System Architect, designing the complete application architecture, communication pipeline, and AI integration workflow.
> Developed the application using Unity, C#, and Mixed Reality (MR) technologies.
> Designed the solution to be compatible with any MR headset.
> Implemented real-time capture and transmission of the user's field of view to a local AI inference server.
> Integrated immersive 3D guidance, contextual annotations, and AI-generated overlays within the MR environment.
> Optimized the communication pipeline to achieve AI response times below 10 seconds.
> Integrated a locally hosted AI model trained on ship-specific technical documentation and maintenance procedures to provide accurate contextual assistance.







Painting Simulator

As the Lead Developer, I developed a VR-based Industrial Painting Training Simulator for Edgeforce Solutions Pvt. Ltd. to provide a realistic and immersive training experience while significantly reducing paint consumption, material wastage, equipment wear, and overall training costs.

The simulator features Basic, Intermediate, and Advanced training modules. The Basic module introduces painting equipment, safety procedures, and spray gun operations. The Intermediate module includes a Zebra Board exercise designed to develop muscle memory, hand stability, spray consistency, and proper spray angle. The Advanced module enables trainees to practice on realistic industrial components using HVLP and Airless Spray Guns, with real-time performance evaluation and scoring.

Key Contributions & Technologies

Led the end-to-end development of the simulator using Unity, C#, and the OpenXR Toolkit.
> Created realistic paint spray effects using Unity's Particle System.
> Integrated a physical spray gun using Arduino (C++), with optimized serial communication for low-latency input to Unity.
> Developed custom HLSL shaders to simulate Primer, Base Coat, Matte, and Gloss paint finishes.
> Built gameplay systems, UI, training workflow, scoring, and assessment modules in C#.
> Designed a centralized SQL database to manage student records, training history, performance reports, and admin logs.
> Developed a Node.js backend running on the Master PC for student authentication, session management, and activity tracking.
> Integrated REST APIs and WebSockets to synchronize trainee data and provide real-time communication between Unity and the backend server.
